# Dibujama

Galeria de dibujos de la comunidad.

## Estructura

- `fotos/` - Carpeta temporal donde se ponen las fotos nuevas antes de subirlas.
- `docs/` - Sitio web generado (lo que sirve GitHub Pages).
- `build-gallery.ps1` - Script para regenerar la galeria y subirla.
- `setup-dibujama.ps1` - Script de configuracion inicial.

## Como agregar fotos nuevas

1. Copia las fotos a la carpeta `fotos/`.
2. Ejecuta `build-gallery.ps1` desde la raiz.
3. Espera 1-2 minutos a que GitHub Pages se actualice.
